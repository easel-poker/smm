# OneSMM Tampermonkey Bot for Railway

این پکیج کدهای تمپرمونکی شما را به یک **افزونه بومی گوگل کروم (Chrome Extension)** تبدیل کرده و روی سرور Railway داخل یک مانیتور مجازی (Xvfb) به صورت ۲۴ ساعته اجرا می‌کند.

## محتویات:
* `extension/`: پوشه افزونه کروم حاوی دقیقاً همان کدهای تمپرمونکی
* `Dockerfile`: فایل ساخت کانتینر در Railway با کروم اصلی
* `start.sh`: اسکریپت اجرای مانیتور مجازی و اجرای خودکار افزونه

## نحوه راه‌اندازی در Railway:
1. فایل‌های این پوشه را در یک ریپازیتوری GitHub آپلود کنید.
2. در Railway یک پروژه جدید بسازید و ریپازیتوری را متصل کنید.
3. ریلوِی به طور خودکار بیلد کرده و سیستم ۲۴ ساعته شروع به کار می‌کند!
